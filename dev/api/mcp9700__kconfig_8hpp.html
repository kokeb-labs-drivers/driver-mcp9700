Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_MCP9700_* Kconfig options.

Copyright
Copyright (c) 2026 The driver-mcp9700 authors. SPDX-License-Identifier: MIT

Include it only where menuconfig should choose the defaults; without Kconfig KconfigDefaults() equals Config{}. One configuration per program: every translation unit of one program must see the same CONFIG_ values, and no driver header includes this one (handbook KB-CPP20-018).
