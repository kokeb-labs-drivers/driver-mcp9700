Detailed Description

The ADC port of the MCP970x driver: the CRTP base, its pin enums, the AdcPort concept and the output-load limits a port must respect.

The sensor has an analog output read through an ADC channel of your MCU. The driver calls hooks on a class you derive from mcp9700::AdcInterface<Self>:

Required: bool EnsureInitialized() noexcept (bring the ADC up on the first call) and bool ReadVoltageMv(uint8_t channel, uint32_t& voltage_mv) noexcept (one calibrated conversion in millivolts at the ADC pin; false on any failure). void DelayUs(uint32_t us) noexcept is required in effect: the first wait is a compile error without it. Optional: bool GpioSet(CtrlPin, GpioSignal) noexcept (powers the sensor from an MCU pin, DS20001942L Section 4.2, p.11; idle INACTIVE before the output is enabled) and void Log(LogLevel, const char*) noexcept (plain text, never a format). The full contract of each hook is the table in docs/porting.md.

The hook is the standard millivolt hook of the driver contract, so one ADC port serves every analog-input driver. The port exposes no raw counts; the application declares the port's full scale and resolution in Config.
