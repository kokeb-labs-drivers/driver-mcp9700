Detailed Description

Public types of the MCP970x driver: errors, Result<T>, the variant table, configuration, presets, Validate() and the pure conversion functions.

The sensor's transfer function is first order, V_OUT = V_0C + T_C x T (datasheet DS20001942L, Equation 4-1, p.10). Temperatures are milli-degrees Celsius (_mc), voltages millivolts (_mv), coefficients microvolts per degree (_uv_per_c); the driver uses integers only. One constexpr table holds the five named parts; Variant::Custom takes a fully declared first-order part.
