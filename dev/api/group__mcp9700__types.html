◆ Error

enum class mcp9700::Error : uint8_t
strong

Why a call failed. Values 0 to 9 are the shared base set; chip-specific values start at 16.

An analog sensor has no bus protocol and no fault register: Timeout, Crc, Busy and DeviceFault are never returned; its faults are OutputLow, OutputHigh, Saturated and Unstable.

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded, or Deinitialize()/Sleep() ran since.

InvalidArgument 

Validate() failed (at EnsureInitialized()); nothing was sent.

Bus 

The port's ADC bring-up, a conversion or a pin write failed.

Timeout 

Not returned by this driver.

DeviceIdMismatch 

Start-up found no plausible, stable output on the channel.

Crc 

Not returned by this driver.

Busy 

Not returned by this driver.

DeviceFault 

Not returned by this driver.

Unsupported 

Sleep() needs the optional GpioSet() hook and the port has none.

OutputLow 

The output is below the specified range minus the margin.

OutputHigh 

The output is above the specified range plus the margin.

Saturated 

A conversion is within one LSB of the declared full scale, or above it.

Unstable 

The conversions of one reading differ by more than max_spread_mv.

◆ Variant

enum class mcp9700::Variant : uint8_t
strong

Which part of the family is wired up: one of the five datasheet devices, or Custom.

The parts cannot be told apart at run time (they differ in accuracy grade, not in transfer function, except the MCP9701 family), so this is a declaration by the user, never detected.

Enumerator
Mcp9700 

500 mV at 0 C, 10.0 mV/C, -40 to +125 C (High: +150 C), accuracy +-4 C.

Mcp9700A 

As the MCP9700 with the +-2 C grade (0 to +70 C).

Mcp9700B 

As the MCP9700 with the +-1 C grade (+20 to +70 C); High option to +150 C.

Mcp9701 

400 mV at 0 C, 19.5 mV/C, -10 to +125 C, accuracy +-4 C.

Mcp9701A 

As the MCP9701 with the +-2 C grade (0 to +70 C).

Custom 

Another first-order linear sensor, fully declared in Config::custom.

constexprnoexcept

The error limits the datasheet guarantees at a temperature (first band that contains it, narrowest first). With High only the High-option rows (-40 to +150 C) apply over the whole range: the datasheet does not say that an H part also meets the tighter Extended rows. For a named variant they hold at its tested supply; the driver never applies them to a reading.

Parameters
specThe variant row.
rangeThe temperature class.
temperature_mcTemperature in milli-degrees Celsius.
Returns
The limits, or InvalidArgument outside the specified range (or High on a row without that class).
