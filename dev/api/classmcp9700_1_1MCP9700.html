Detailed Description

template<AdcPort Port>
class mcp9700::MCP9700< Port >

Driver for one MCP970x analog temperature sensor (or a declared Custom part) on an ADC port.

Lifecycle: construct with the configuration (no I/O), then EnsureInitialized(), the one way to start, use, optionally Deinitialize() or Sleep(). Every call that touches the sensor returns Error::NotInitialized until EnsureInitialized() has succeeded; no call starts it as a side effect.

Hooks beyond the two required ADC ones: void DelayUs(uint32_t) (required by every wait: a missing one is a compile error), bool GpioSet(CtrlPin, GpioSignal) (the sensor's supply from an MCU pin; without it Sleep() returns Unsupported), void Log(LogLevel, const char*).

A reading never retries and never clamps: a failed read is reported once, and a failed read does not uninitialise the driver.

Mark the driver uninitialised and switch the sensor off when the port has GpioSet(); the next EnsureInitialized() starts it again (the recovery after a fault). Ok with no I/O when it was not initialised.

Returns
Ok or Bus (the pin write failed; the driver is uninitialised either way and the sensor may still be powered). A second Deinitialize() does nothing; to retry the switch-off call EnsureInitialized() and then Sleep() or Deinitialize() again.

◆ EnsureInitialized()

template<AdcPort Port>
Result< void > mcp9700::MCP9700< Port >::EnsureInitialized ( )
noexcept

Start the sensor, once: the only way to initialise the driver.

Checks the configuration, brings the ADC up, powers the sensor (GpioSet, when the port has it), waits power_on_settle_us (the datasheet gives t_ON typical only, 800 us), then takes one validated reading: the analog equivalent of a chip-ID check. After it succeeds, later calls return Ok at once with no I/O. After it fails the sensor is switched off again (best effort), the driver stays uninitialised and the next call starts again.

Returns
Ok, InvalidArgument (the configuration fails Validate(); no I/O), Bus, or DeviceIdMismatch (no plausible, stable output on the channel).

The validated reading: discard_conversions dummy conversions, then samples averaged.

Sends exactly discard_conversions + samples conversions, never retries. Checks, in this order of precedence: Bus (stops at the first failed conversion), Saturated, Unstable, then OutputLow / OutputHigh against the specified range plus range_margin_mc.

Returns
The measurement, or NotInitialized, Bus, Saturated, Unstable, OutputLow or OutputHigh.
